    Argus
    
      
    
    
    
    名字來自希臘神話裡的百眼巨人 Argus Panoptes：身上的眼睛輪流守望，從不全部閉上。
      Argus 也一樣，請好幾個開源掃描工具一起看，再把結果整理成一份白話中文報告。
    
    
    Argus 自己做的檢查
    
    
      
      
    • 能力一覽：讀技能的程式和 SKILL.md，標出它會不會連網、執行程式、寫入檔案、碰觸機密、自動執行、安裝套件。
      • 
      
    • MCP 伺服器檢查：讀 Claude Code、Claude 桌面版、外掛和 Cursor 的設定，看版本有沒有鎖定、連線有沒有加密、金鑰是不是寫在設定裡。
      • 
      
    • 已看過和更新比對：記住你看過的技能，作者更新時告訴你改了什麼。
      • 
      
    • 「多半不用擔心」分組：依固定規則把明顯的誤判收起來，不會改變各工具的結論。
      • 
    
    
    
    版權與授權
    
    
    。Argus 以 MIT 授權開源，可以自由使用、修改和分享。
    
    
    使用的開源掃描工具
    
    
      
    
      Argus 不夾帶這些工具的程式，而是在你的電腦上安裝各自的官方版本，並遵守各自的授權條款。
      
    
      隱私
      
    
        
      
      • 所有掃描都在你的電腦上進行，技能內容不會被上傳，也不會送給 AI 服務。
        • 
      
      • 檢查 MCP 伺服器時只讀取設定檔，不會啟動任何伺服器；設定裡的金鑰在報告中一律遮住。
        • 
      
      • 「已看過」的紀錄和每次掃描的比對資料，只存在你的電腦上。
        • 
      
      • 會連網的情況只有：安裝工具、下載你指定的 GitHub 技能、查詢套件有沒有已知漏洞（只送出套件名稱到 OSV.dev）、到 GitHub 查 Argus 有沒有新版本（每次打開 Argus 時，或按「檢查更新」時），以及你按「立即更新」時下載新版。這些都不會送出任何技能或報告的內容。
        • 
      
      • 這個頁面只在你的電腦上運作（127.0.0.1），其他電腦連不進來。
