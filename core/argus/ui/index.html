1要檢查什麼？

會檢查 ~/.claude/skills 和已安裝外掛裡的每一個技能。

還沒選擇

會讀取 Claude Code、Claude 桌面版、外掛和 Cursor 的設定檔，檢查每個 MCP 伺服器怎麼執行、連到哪裡、有沒有把金鑰寫在設定裡。只讀設定，不會啟動任何伺服器。這項由 Argus 自己檢查，不需要安裝下面的工具。

2用哪些工具？

建議全部勾選，各工具擅長的地方不同。第一次用要先安裝，每個大約 1–3 分鐘；可以按「全部安裝」一次裝好，也可以一個一個裝。工具出新版時，旁邊會寫「可更新到」。

      Argus 自己做的檢查
      
        
        
          
      • 一句話結論報告最上面直接寫「可以裝／先問人／不建議」。
        • 
          
      • 能力一覽標出技能會不會連網、執行程式、寫入檔案、碰觸機密、自動執行、安裝套件。
        • 
          
      • 「多半不用擔心」分組依固定規則把明顯的誤判收起來，不會改變各工具的結論。
        • 
          
      • 已看過和更新比對記住你看過的技能，作者更新時告訴你改了什麼。
        • 
          
      • 重新檢查提醒Claude 技能有更新、新裝或超過 30 天沒檢查時提醒你。
        • 
          
      • MCP 伺服器檢查讀 Claude 和 Cursor 的設定，看版本鎖定、連線加密、金鑰保管。
        • 
          
      • 外掛 hooks 檢查列出外掛會自動執行的指令，標出會自己連網、下載並執行程式的。
        • 
          
      • 檔案檢查標出掃描工具讀不了的程式、壓縮檔，以及沒鎖版本的套件。
        • 
          
      • Semgrep 檢查規則針對 AI 技能寫的 JavaScript／TypeScript 規則，只在你的電腦上執行。
        • 
          
      • 工具更新提醒掃描工具出新版時，工具旁邊會出現「有新版」。
        • 
          
      • 在 Claude 裡直接檢查在 Claude Code 說「幫我檢查這個技能」，Claude 會自己用 Argus 掃描。
        • 
          
      • 新技能自動檢查Mac 上裝了新技能或技能更新時，在背景自動檢查並提醒你。
        • 
        
      
      
      
      
      
        
        
          
      • 所有掃描都在你的電腦上進行，技能內容不會被上傳，也不會送給 AI 服務。
        • 
          
      • 檢查 MCP 伺服器時只讀設定檔，不會啟動任何伺服器；金鑰在報告中一律遮住。
        • 
          
      • 「已看過」的紀錄、比對資料和各工具花的時間，只存在你的電腦上。
        • 
          
      • 這個頁面只在你的電腦上運作（127.0.0.1），其他電腦連不進來。
        • 
          
      • Claude 裡的 Argus 技能和自動檢查，都是在你的電腦上執行同一套掃描，不會多送出任何東西；Claude 讀到的只有掃描結果。
