      2.

      3. 
      
    3. 點兩下打開新版。Mac 會再擋一次，到「系統設定 → 隱私權與安全性」按「仍要打開」。
      4.

    名字來自希臘神話裡的百眼巨人 Argus Panoptes：身上的眼睛輪流守望，從不全部閉上。Argus 也一樣，請好幾個開源掃描工具一起看，再整理成一份白話中文報告。
    
        
    Argus 自己做的檢查
    
        
      
          
    • 一句話結論報告最上面直接寫「可以裝／先問人／不建議」。
      • 
          
    • 能力一覽標出技能會不會連網、執行程式、寫入檔案、碰觸機密、自動執行、安裝套件。
      • 
          
    • 「多半不用擔心」分組依固定規則把明顯的誤判收起來，不會改變各工具的結論。
      • 
          
    • 已看過和更新比對記住你看過的技能，作者更新時告訴你改了什麼。
      • 
          
    • 重新檢查提醒Claude 技能有更新、新裝或超過 30 天沒檢查時提醒你。
      • 
          
    • MCP 伺服器檢查讀 Claude 和 Cursor 的設定，看版本鎖定、連線加密、金鑰保管。
      • 
          
    • Semgrep 檢查規則針對 AI 技能寫的 JavaScript／TypeScript 規則，只在你的電腦上執行。
      • 
          
    • 工具更新提醒掃描工具出新版時，工具旁邊會出現「有新版」。
      • 
        
    
      
    
      
    
        
      
          
    • 所有掃描都在你的電腦上進行，技能內容不會被上傳，也不會送給 AI 服務。
      • 
          
    • 檢查 MCP 伺服器時只讀設定檔，不會啟動任何伺服器；金鑰在報告中一律遮住。
      • 
          
    • 「已看過」的紀錄、比對資料和各工具花的時間，只存在你的電腦上。
      • 
          
    • 這個頁面只在你的電腦上運作（127.0.0.1），其他電腦連不進來。
