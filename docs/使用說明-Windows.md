# Argus（Windows 版）：使用說明

**Argus** 是一個 Windows 小工具：在安裝 Claude 等 AI 工具的「技能」（Skill）之前，請好幾個開源安全掃描工具一起檢查，再把結果整理成一份白話中文報告。

名字來自希臘神話裡的百眼巨人 Argus：身上的眼睛輪流守望，從不全部閉上。

---

## 需要什麼

- Windows 10 或 Windows 11（一般 Intel／AMD 電腦或 ARM 電腦都可以）
- 第一次使用時需要網路（安裝 Argus 需要的程式和掃描工具）
- 不需要另外安裝 Python 或 Git

---

## 第一次使用

1. **解壓縮**：在下載的 `Argus-win-版本.zip` 上按右鍵 →「**全部解壓縮**」，得到「Argus」資料夾。
   （一定要先解壓縮，直接在 zip 裡面點兩下會打不開。）
2. **放好位置**：把整個 Argus 資料夾放到你找得到、之後不會亂搬的地方，例如「文件」。
3. **第一次打開**：點兩下資料夾裡的 **Argus.cmd**。這個工具不是從 Microsoft Store 下載的，Windows 可能會先擋下來，這是正常的：
   - 出現藍色的「**Windows 已保護您的電腦**」：按「**其他資訊**」→「**仍要執行**」。
   - 出現「**開啟檔案 - 安全性警告**」：按「**執行**」。
4. **安裝 uv**：第一次會問要不要安裝 uv（用來安裝掃描工具的免費開源小程式），按「**是**」。
5. **等它打開**：第一次啟動要下載一些東西，大約 1 分鐘，會有一個小視窗顯示進度，之後瀏覽器會自動打開 Argus 的頁面。
6. **安裝掃描工具**：在「用哪些工具？」裡，按每個工具旁邊的「**安裝**」，每個大約 1–3 分鐘。建議全部裝。

第一次打開後，**開始功能表**和**桌面**都會出現有 Argus 圖示的捷徑，之後從那裡打開就好，不用再找 Argus.cmd。

## 怎麼用

### 1. 要檢查什麼？

| 選項 | 用途 |
|---|---|
| 我所有的 Claude 技能 | 自動找出這台電腦上 Claude 的技能和外掛（`C:\Users\你的名字\.claude` 裡），一次全部檢查 |
| 一個資料夾 | 選一個下載下來、還沒安裝的技能資料夾 |
| 一個 zip 檔 | 選一個技能的 zip 檔 |
| GitHub 網址 | 貼上公開 repo 的連結，也可以是裡面某個資料夾的連結 |
| 我的 MCP 伺服器 | 檢查 Claude Code、Claude 桌面版、外掛和 Cursor 裡設定的 MCP 伺服器。只讀設定檔，不會啟動任何伺服器，也不需要安裝掃描工具 |

一個資料夾、zip 或 repo 裡有好幾個技能時，會分開檢查，報告裡每個技能各一張卡片。

### 2. 用哪些工具？

| 工具 | 擅長 |
|---|---|
| **SkillSpector**（NVIDIA） | 專門檢查 AI 技能：提示詞注入、資料外流、危險指令、套件漏洞等 70 多種寫法 |
| **Cisco Skill Scanner**（Cisco） | 另一套專門檢查 AI 技能的規則，當作第二意見 |
| **Bandit**（PyCQA） | 檢查技能裡的 Python 程式有沒有危險寫法；沒有 Python 程式的技能會顯示「不適用」 |
| **detect-secrets**（Yelp） | 找技能裡有沒有寫死的密碼、API 金鑰 |

### 3. 開始檢查

按「開始檢查」，頁面會顯示進度。完成後報告直接出現在頁面上，也會存一份在「文件 → Argus 報告」資料夾。之前的報告可以在首頁的「最近的報告」找回來。

看完報告，直接關掉瀏覽器分頁就好，Argus 會在幾分鐘後自動結束。

### 更新 Argus

有新版本時，首頁上方會出現「**有新版本**」的提示（每次打開 Argus 時檢查；也可以在「關於」按「**檢查更新**」）：

- 按「**立即更新**」：Argus 會自己下載新版、確認是官方的新版本、換掉舊版，再自動重新打開。掃描工具和之前的報告都會保留，捷徑也不用重建。
- 按「**手動更新**」：照視窗裡的步驟自己下載、取代。
- 按「**稍後再說**」：這個版本就不會再提醒。

如果自動更新失敗（例如有 Argus 資料夾的視窗開著、檔案正在使用中），Argus 會維持原本的版本，關掉那個視窗再試，或改用手動更新即可。

## 怎麼看報告

最上面是幾個數字：

- 🟢 **安全**：沒有發現需要擔心的地方。
- 🟡 **注意**：有幾個地方值得看一眼，通常是正常功能。
- 🔴 **不建議安裝**：有高風險的寫法，建議先看每一條說明再決定。

每個技能底下的發現分成「**需要看的**」和「**多半不用擔心的**」兩組。後者是依固定規則挑出來的明顯誤判，每一條都寫了「為什麼不用擔心」。

拿不準的話，按「**複製給 Claude 判斷**」，貼到 Claude 對話裡送出，Claude 會逐條告訴你哪些是真的要擔心。

> **「不建議安裝」不等於有惡意。** 掃描工具只看寫法、不看用途，很常把正常功能也標起來。

### 能做的事（能力一覽）

每個技能的名稱下方，有一排圖示標出它**會做的事**：

| 圖示 | 意思 |
|---|---|
| 🌐 連網 | 會連到網路上的服務或下載東西 |
| ⚙️ 執行程式 | 會在你的電腦上執行程式或指令 |
| 📁 寫入或刪除檔案 | 會建立、修改或刪除檔案 |
| 🔑 碰觸機密或 Claude 設定 | 會讀取金鑰、.env 檔或 Claude 的設定資料夾 |
| ⚡ 自動執行 | 會在特定時機自動執行，不用你叫它 |
| 📦 安裝套件 | 會安裝其他程式或套件 |
| 📄 只有文字說明 | 以上都沒有，只是給 AI 看的說明文字 |

點一下圖示，可以看到 Argus 是根據哪個檔案的哪一行判斷的。可以用來檢查「這個寫劇本的技能，為什麼要連網？」這類不合理的地方。這是 Argus 依檔案內容推測的，不是保證。

### 標記為已看過

看完一個技能、覺得沒問題，按卡片下方的「**標記為已看過**」。之後再掃描時：

- **沒有變動**：標示「✓ 已看過」，之前看過的發現會收到「之前看過的」，不用再看一次。
- **作者更新了這個技能**：標示「⚠ 你看過之後，這個技能有更新」，並列出新增、修改、刪除了哪些檔案；新出現的發現會標上紅色的「新」。

這可以防範一種常見手法：技能一開始很乾淨，等大家都裝了，才在更新時偷偷加料。沒標過已看過的技能，Argus 也會跟上一次掃描比較，有變動就提醒。再按一次可以取消。

這個按鈕只在 Argus 裡打開報告時才會出現；直接打開存下來的報告檔案時沒有。

### MCP 伺服器的報告

選「我的 MCP 伺服器」時，每個伺服器各一張卡片，標出它設定在哪裡、怎麼執行（或連到哪個網址），以及這些提醒：

- **版本沒鎖定**：每次啟動都下載最新版，作者或盜用帳號的人發佈新版時，你的電腦會直接執行。
- **連線沒有加密**：用 http:// 連到外部服務。
- **金鑰直接寫在設定檔裡**：保管習慣的提醒，金鑰在報告裡一律遮住。
- **Docker 權限太高、能存取整個家目錄**：給的權限超過一般需要。

這些多半是設定習慣的問題，不代表伺服器有惡意；拿不準的話一樣可以按「複製給 Claude 判斷」。

## 隱私與安全

- 「已看過」的紀錄和每次掃描的比對資料，只存在你的電腦上，不會上傳。
- 檢查 MCP 伺服器時，Argus 只讀取設定檔，不會啟動伺服器；設定裡的金鑰在報告中一律遮住。
- 所有掃描都在你的電腦上進行，**技能內容不會被上傳**，也不會送給 AI 服務。
- 只有這些情況會連網：安裝 Argus 需要的程式和掃描工具、下載你指定的 GitHub 技能、查詢套件有沒有已知漏洞（只送出套件名稱到 [OSV.dev](https://osv.dev)）、到 GitHub 查 Argus 有沒有新版本並在你按「立即更新」時下載。
- Argus 的頁面只在你的電腦上運作（網址是 127.0.0.1），其他電腦連不進來。

## 常見問題

**點兩下後出現「Windows 已保護您的電腦」**
照上面「第一次打開」的步驟，按「其他資訊」→「仍要執行」。之後從開始功能表或桌面的捷徑打開，就不會再出現。

**點兩下後過了很久，瀏覽器都沒打開**
第一次啟動要下載 Python，網路慢時可能要 2–3 分鐘。超過 3 分鐘還沒打開，會跳出錯誤訊息；紀錄在 `%APPDATA%\Argus\logs`（在檔案總管的網址列貼上這串就能打開）。

**選資料夾的視窗沒出現**
有時會開在瀏覽器後面，看一下工作列。

**畫面卡住、按什麼都沒反應**
按右上角「關於」→「**結束 Argus**」，再重新打開 Argus。

**某個工具安裝失敗或顯示「沒掃完」**
確認網路正常後再試一次；報告上「沒掃完」括號裡會寫出原因。工具壞掉時首頁會顯示「重新安裝」。

**公司電腦打不開或裝不起來**
公司配發的電腦可能禁止執行 PowerShell 腳本或安裝軟體，請先詢問公司 IT。

**想移除**
刪掉 Argus 資料夾、開始功能表和桌面的 Argus 捷徑即可。報告在「文件 → Argus 報告」，要不要留由你決定。
