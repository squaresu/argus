# Argus：使い方

**Argus** は Mac 用の小さなツールです。Claude などの AI ツールに「スキル」（Skill）をインストールする前に、いくつものオープンソースのセキュリティスキャナーでまとめてチェックし、その結果をわかりやすい言葉のレポートにまとめます。

名前は、ギリシャ神話に登場する百の目を持つ巨人 Argus から取りました。体じゅうの目が交代で見張り、すべての目を閉じることはありません。

---

## 必要なもの

- Mac（macOS 11 以降。Intel チップでも M シリーズチップでも使えます）
  - Cisco Skill Scanner には macOS 13 以降が必要です
  - macOS 13 より前の Mac では、SkillSpector をインストールする前に Apple の「コマンドライン・デベロッパ・ツール」が必要です（Argus が案内します）
- 初めて使うときはインターネット接続が必要です（Argus が使うプログラムとスキャナーをインストールするため）
- Python や Git を別途インストールする必要はありません

---

## はじめて使うとき

1. **展開する**：ダウンロードした `Argus-mac-バージョン.zip`（例：`Argus-mac-2.0.1.zip`）をダブルクリックすると、「Argus」が出てきます。
2. **置き場所を決める**：Argus を「アプリケーション」フォルダにドラッグします。
   - 以前「SkillSpector 掃描」を使っていた場合は、ゴミ箱に入れてかまいません。インストール済みの SkillSpector はそのまま使えるので、入れ直す必要はありません。
3. **はじめて開く**：ダブルクリックして開きます。このアプリは App Store からダウンロードしたものではないため、最初は Mac にブロックされます。これは正常な動きです。
   - **新しい macOS（Sequoia 以降）**：「完了」を押して表示を閉じる →「システム設定」→「プライバシーとセキュリティ」→ 下にスクロールして「Argus」についてのメッセージを探す →「**このまま開く**」を押す → もう一度確認します。
   - **古い macOS**：アプリのアイコンを右クリック →「開く」→ もう一度「開く」を押します。
4. **uv をインストールする**：初回は uv（スキャナーをインストールするための無料・オープンソースの小さなプログラム）をインストールするか聞かれるので、「インストール」を押します。
5. **開くまで待つ**：初回の起動ではいくつかダウンロードが必要で、1 分ほどかかります。そのあと、ブラウザで Argus のページが自動的に開きます。
6. **スキャナーをインストールする**：「どのスキャナーを使う？」の右上にある「**すべてインストール**」を押すと、すべてのスキャナーが順番にインストールされます（1 つにつき 1〜3 分ほど）。各スキャナーの横の「インストール」で 1 つずつ入れることもできます。すべて入ると、この欄は 1 行にたたまれます。変更したいときは「調整」を押してください。

次からは、Argus をダブルクリックするだけでページが開きます。

## 使い方

> Argus は最初はダークモードで表示されます。ライトにしたいときは、右上の月のボタンを押してください。もう一度（太陽）押すとダークに戻ります。
> 表示言語は、お使いのパソコンの言語に自動で合わせます。変えたいときは、右上のテーマ切り替えボタンの横で選べます。

### 1. 何をチェックする？

| 選択肢 | 内容 |
|---|---|
| 自分の Claude スキル | この Mac にある Claude のスキルとプラグインを自動で見つけて、まとめてチェックします |
| フォルダ | ダウンロードしたけれど、まだインストールしていないスキルのフォルダを選びます |
| zip ファイル | スキルの zip ファイルを選びます |
| GitHub の URL | 公開リポジトリのリンクを貼り付けます。リポジトリ内の特定のフォルダのリンクでもかまいません |
| 自分の MCP サーバー | Claude Code、Claude Desktop、プラグイン、Cursor に設定されている MCP サーバーをチェックします。設定ファイルを読むだけで、サーバーを起動することはありません。スキャナーのインストールも不要です |

1 つのフォルダ、zip、リポジトリに複数のスキルが入っている場合は、別々にチェックします。レポートでは、スキルごとに 1 枚のカードになります。

### 2. どのスキャナーを使う？

| スキャナー | 得意なこと |
|---|---|
| **SkillSpector**（NVIDIA） | AI スキル専用のチェック。プロンプトインジェクション、データの持ち出し、危険なコマンド、パッケージの脆弱性など、70 種類以上の書き方を見つけます |
| **Cisco Skill Scanner**（Cisco） | AI スキル専用の、もう 1 つのルール。セカンドオピニオンとして使います |
| **Bandit**（PyCQA） | スキルに含まれる Python プログラムに危険な書き方がないかを調べます。Python プログラムがないスキルでは「対象外」と表示されます |
| **Semgrep**（Semgrep） | Argus 独自のルールで、スキルに含まれる JavaScript／TypeScript プログラムを調べます。コマンドの実行、文字列をプログラムとして実行すること、キーのファイルの読み取り、起動時の設定の変更、怪しい場所へのデータ送信などです。こうしたプログラムがないスキルでは「対象外」と表示されます |
| **detect-secrets**（Yelp） | スキルにパスワードや API キーが直接書き込まれていないかを探します |
| **OSV-Scanner**（Google） | スキルが使うパッケージに既知の脆弱性がないか、悪意のあるパッケージとして報告されていないかを調べます。バージョンが明記されたパッケージ一覧（package-lock.json や、== が書かれた requirements.txt など）だけが対象で、ない場合は「対象外」と表示されます。**パッケージ名とバージョンを OSV.dev に送って照会します**。スキルの中身は送りません |

**Argus 自身もチェックします：**
- **ファイル**：スキャナーが読めないファイル（コンパイル済みのプログラムや圧縮ファイル）が含まれていないか、バージョンが固定されていないパッケージ一覧がないかを調べます。
- **プラグインのフックとコマンド**（「自分の Claude スキル」をチェックするとき）：プラグインはフック（自動で実行されるコマンド）を設定でき、あなたがメッセージを送るたびや、Claude がツールを使うたびにコマンドを自動で実行できます。Argus は各プラグインが自動で実行するコマンドをすべて一覧にし、勝手にネットに接続する、プログラムをダウンロードして実行する、キーに触れる、起動時の設定を変えるといったものに印を付けます。それらが使うプログラムもチェックします。レポートには「プラグイン名（プラグインのフック、コマンド、プログラム）」として表示されます。

**スキャナーの新しいバージョンが出たとき：** Argus を開くと、新しいバージョンがあるスキャナーの横に「新しいバージョン x.y」と「更新」ボタンが表示されます。押すと新しいバージョンに入れ替わります（1〜3 分ほど）。Argus は PyPI と GitHub にバージョン番号を問い合わせるだけで、ほかの内容は何も送りません。スキャナーは自動では更新されないので、「新しいバージョン」が表示されたら更新するのがおすすめです。特に SkillSpector と Cisco は、新しい攻撃の手口を見つけるには新しいルールが必要です。

スキャナーはそれぞれ得意分野が違うので、すべてにチェックを入れておくのがおすすめです。

### 3. チェック開始

「チェック開始」を押すと、ページに進み具合が表示されます。終わるとレポートがそのままページに表示され、「書類 → Argus 報告」フォルダにも保存されます。以前のレポートは、ホーム画面の「最近のレポート」から開けます。

「チェック開始」の横には、スキルの数と**だいたいの所要時間**が先に表示されます（GitHub の URL と zip ファイルは、ダウンロードして展開するまでスキルの数がわからないため、まずスキル 1 つあたりの目安を表示します）。チェック中の画面には、経過時間と残りの目安が表示されます。目安は使うほど正確になります。Argus は、あなたのパソコンで各スキャナーに実際にかかった時間を覚えておくからです。

### チェックし直しのお知らせ

Argus を開いたとき、Claude のスキルが次のような状態だと、ホーム画面のいちばん上にお知らせが表示されます。

- 前回のチェックのあとで、スキルのファイルが更新された
- まだチェックしていないスキルを新しく入れた
- 30 日以上チェックしていない

「**今すぐチェック**」を押すと「自分の Claude スキル」が選ばれた状態になります。「あとで」を押すと、7 日間はお知らせしません（新しい更新があった場合は除きます）。Argus はファイルを比べるだけで、勝手にスキャンを始めることはありません。

スキルが多くて時間がかかるときは、進み具合の画面の下にある「**チェックを中止**」を押せます。チェックが終わった分は、そのままレポートになります。

レポートを読み終えたら、ブラウザのタブを閉じるだけでかまいません。Argus は数分後に自動で終了します。

### Claude と一緒に使う

ホーム画面の下のほうにある「**Claude と一緒に使う**」には、スイッチが 2 つあります。

**Claude から Argus にチェックを頼む**
オンにすると、Argus が Claude に「argus」というスキルを追加します。そのあとは **Claude Code**（ターミナル、または Claude Desktop の Code タブ）で、次のように頼むだけです。

- 「このスキルをチェックしてからインストールして：https://github.com/…」
- 「入れているスキルは安全？」
- 「MCP サーバーをチェックして」

Claude が自分で Argus を使ってスキャンし、結果をわかりやすく伝えてくれます。Argus を開いたり、コピー＆ペーストしたりする必要はありません。Claude にスキルのインストールを頼んだときも、先にチェックして結論を伝えてからインストールします。

> 通常の Claude のチャット（Web 版やスマートフォンアプリ）は、あなたのパソコンでプログラムを実行できません。そのため、このスキルを使えるのは Claude Code だけです。
> 裏では Argus が作った `argus` コマンド（`~/.local/bin/argus`）を使っています。Argus は開くたびにこのコマンドを更新するので、Argus を移動したり更新したりしたあとは、一度開くだけで大丈夫です。

**新しく入れたスキルを自動チェック**（Mac）
オンにすると、新しい Claude のスキルやプラグインを入れたときや、スキルが更新されたときに、Argus がバックグラウンドで**新しく入れたもの・変わったものだけ**を自動でチェックします。

- 問題がなければ：右上に通知が表示されます。
- 「まず確認を」か「非推奨」があれば：ウインドウが表示されます。「**レポートを開く**」を押すと確認できます。
- レポートは、ホーム画面の「最近のレポート」にも表示されます。

スイッチをオンにする前から入っていたスキルは、自動ではスキャンし直しません。チェックしたいときは「自分の Claude スキル」で一度スキャンしてください。Argus を開いていなくても動きます。スイッチをオフにすると止まります。

### Argus を更新する

新しいバージョンがあると、Argus のホーム画面の上のほうに「**新しいバージョンがあります**」と表示されます（Argus を開くたびに確認します。「このアプリについて」の「**アップデートを確認**」からも確認できます）。

- 「**今すぐ更新**」を押す：Argus が新しいバージョンをダウンロードし、公式のものであることを確かめてから古いバージョンと入れ替え、自動で開き直します。自分でダウンロードしたり、ファイルをドラッグしたりする必要はありません。スキャナーとこれまでのレポートもそのまま残ります。
- 「**手動で更新**」を押す：ウインドウに表示される手順に従って、自分でダウンロードして入れ替えます。
- 「**あとで**」を押す：このバージョンについては、もうお知らせしません。

ご注意：

- 自動で更新するには、Argus が「アプリケーション」フォルダに入っている必要があります。
- 新しい macOS では、初めて自動更新するときに、Argus によるアプリの更新を許可するか聞かれることがあります。許可してください。ブロックされた場合は Argus は元のバージョンのままなので、「手動で更新」を使ってください。
- 2.0.2 より前のバージョンにはこの機能がありません。一度だけ手動で 2.0.2 に更新すれば、その後はワンクリックで更新できます。
- 更新前の古いバージョンは 1 つ残しておくので、万一新しいバージョンに問題があっても元に戻せます。

## レポートの見かた

レポートのいちばん上には**ひと言の結論**があります。全部読まなくても、どうすればよいかがわかります。

- 🟢 **インストールして大丈夫**（インストール済みのスキルや MCP サーバーでは「このまま使って大丈夫」）：心配な点はないか、印が付いたものはすべて「たぶん心配なし」に入っています。
- 🟡 **まず確認を**：確認したほうがよい点がいくつかあります。迷ったら「Claude に判断してもらう（コピー）」を押すか、詳しい人に聞いてください。
- 🔴 **おすすめしません**：危険度の高い書き方があります。正常な機能だと確信できないなら、ひとまず使わないでください。

たくさんのスキルを一度にチェックしたときは、結論に「非推奨がいくつ、まず確認をがいくつ」と書かれ、その名前が並びます。名前を押すと、そのスキルに移動します。「このまま使って大丈夫」なスキルは、名前を 1 行にまとめていちばん最後に置いてあり、開くと詳細が見られます。スキルが多いレポートでは、上にフィルターの列があり、特定の結論だけを表示したり、名前でスキルを探したりできます。各カードの「詳細」には、スキャナーごとの結果とスキルのできることが載っています。保存したいときや人に見せたいときは、ブラウザの「印刷」→「PDF として保存」を使ってください。

同じスキャナーの同じ種類の指摘は、たとえば「14 か所」のように 1 枚のカードにまとめます。14 回くり返して並べることはありません。

結論は、Argus が決まったルールでまとめたものです。まずスキャナーごとの結論を見て（いちばん重いものを採用）、そこから「たぶん心配なし」と、以前に確認した指摘を除きます。カードには、たとえば「SkillSpector おすすめしません · Cisco 注意 · Bandit 安全」のように、スキャナーごとの結論も表示されます。

各スキルの指摘は 2 つのグループに分かれます。

- **確認したほうがよい点**：開いて 1 つずつ見るのがおすすめです。
- **たぶん心配なし**：決まったルールで選び出し、先にたたんであるものです。どれにも「心配しなくてよい理由」が書いてあります。たとえば、ただの注意書きである、Web ページのスタイルファイルに出てくるだけ、サンプルファイルの中のダミーのキーにすぎない、などです。

どの指摘にも、見つけたスキャナーの名前と、**説明**・**抜粋**・**判断のしかた**が付いています。

> **大切：「おすすめしません」は「悪意がある」という意味ではありません。**
> スキャナーは書き方だけを見て、目的までは見ません。そのため、ファイル変換のためにツールを実行する、あなた自身の API キーで公式サービスを呼び出す、といった正常な機能にもよく印を付けます。
> グループ分けは読む順番を整えるためのものです。指摘を隠すことはなく、スキャナーごとの結論も変えません。
> Bandit は AI スキル専用に作られたものではないため、出す結論は「注意」までです。Bandit だけで「おすすめしません」になることはありません。

**迷ったら、Claude に判断してもらいましょう：**

1. レポートの上にある「**レポート全体を Claude に判断してもらう（コピー）**」か、各スキルの下にある「**Claude に判断してもらう（コピー）**」（そのスキルの分だけコピー）を押します。
2. Claude を開き、入力欄に貼り付けて（⌘V）送信します。
3. Claude が、本当に心配すべきものと誤検知を 1 つずつ説明し、最後にインストールしてよいか、何に気をつければよいかを教えてくれます。

### できること（一覧）

各スキルの名前の下には、そのスキルが**すること**を示すアイコンが並びます。

| アイコン | 意味 |
|---|---|
| 🌐 ネットに接続 | インターネット上のサービスに接続したり、何かをダウンロードしたりします |
| ⚙️ プログラムを実行 | あなたのパソコンでプログラムやコマンドを実行します |
| 📁 ファイルの書き込み・削除 | ファイルを作成、変更、削除します |
| 🔑 秘密情報や Claude の設定に触れる | キー、.env ファイル、Claude の設定フォルダを読み取ります |
| ⚡ 自動で実行 | 決まったタイミングで、頼まなくても自動で実行されます |
| 📦 パッケージをインストール | ほかのプログラムやパッケージをインストールします |
| 📄 テキストの説明だけ | 上のどれにも当てはまらず、AI が読むための説明文だけです |

アイコンを押すと、Argus がどのファイルの何行目をもとに判断したかが見られます。「台本を書くスキルなのに、なぜネットに接続するの？」といった、つじつまの合わない点を確かめるのに使えます。これはファイルの内容から Argus が推測したもので、保証ではありません。

### 確認済みにする

スキルを確認して問題ないと思ったら、カードの下にある「**確認済みにする**」を押します。次からスキャンすると、次のように表示されます。

- **変更がない場合**：「✓ 確認済み」と表示され、以前に確認した指摘は「前に確認したもの」にまとめられるので、もう一度見る必要はありません。
- **作者がスキルを更新した場合**：「⚠ 確認したあとで、このスキルが更新されました」と表示され、どのファイルが追加・変更・削除されたかが一覧になります。新しく出てきた指摘には、赤い「新規」の印が付きます。

これは、よくある手口への備えになります。最初はきれいなスキルを配り、みんなが入れたころに、更新でこっそり悪いものを混ぜるという手口です。確認済みにしていないスキルでも、Argus は前回のスキャンと比べて、変わっていればお知らせします。もう一度押すと取り消せます。

このボタンは、Argus の中でレポートを開いたときだけ表示されます。保存したレポートファイルを直接開いたときには表示されません。

### MCP サーバーのレポート

「自分の MCP サーバー」を選ぶと、サーバーごとに 1 枚のカードが作られます。どこに設定されているか、どうやって実行されるか（またはどの URL に接続するか）と、次のような注意点が表示されます。

- **バージョンが固定されていない**：起動するたびに最新版をダウンロードします。作者や、アカウントを乗っ取った人が新しいバージョンを出すと、それがそのままあなたのパソコンで実行されます。大手企業や MCP 公式のパッケージは「たぶん心配なし」に入ります。
- **起動するたびに GitHub の最新コードを取ってくる**：パッケージの配布元を通さず、バージョンの指定もないため、作者が加えた変更がどんなものでもそのまま実行されます。
- **ほかの人から届いたメッセージを Claude に渡す**：Discord、Telegram、iMessage などのプラグインです。ほかの人から届いた文章を、Claude が指示だと受け取って実行してしまうおそれがあります。使っていないならオフにしてください。
- **通信が暗号化されていない**：http:// で外部のサービスに接続しています。
- **キーが設定ファイルに直接書かれている**：保管のしかたについての注意です。レポートでは、キーは必ず伏せて表示されます。
- **Docker の権限が強すぎる、ホームフォルダ全体にアクセスできる**：ふつう必要な範囲を超えた権限を与えています。

これらの多くは設定のしかたの問題で、サーバーに悪意があるという意味ではありません。迷ったときは、同じように「Claude に判断してもらう（コピー）」を使えます。

## プライバシーと安全

- 「確認済み」の記録と、スキャンごとの比較用データは、あなたのパソコンの中だけに保存され、アップロードされることはありません。
- MCP サーバーをチェックするとき、Argus は設定ファイルを読むだけで、サーバーを起動しません。設定に含まれるキーは、レポートでは必ず伏せて表示されます。
- スキャンはすべてあなたのパソコンの中で行われます。**スキルの中身がアップロードされることはなく**、AI サービスに送られることもありません。
- インターネットに接続するのは、次の場合だけです。
  - Argus が使うプログラムとスキャナーをインストールするとき、およびスキャナーの新しいバージョンを確認するとき（バージョン番号だけを確認します）。
  - GitHub の URL でスキャンするときに、そのスキルをダウンロードするとき。
  - スキルが使うパッケージに既知の脆弱性がないかを調べるとき（OSV-Scanner を使う場合。パッケージ名とバージョンだけを [OSV.dev](https://osv.dev) に送ります）。
  - Argus の新しいバージョンを GitHub に確認するとき（Argus を開くたび、または「アップデートを確認」を押したとき）と、「今すぐ更新」を押して新しいバージョンをダウンロードするとき。スキルやレポートの内容は一切送りません。
- Argus のページはあなたのパソコンの中だけで動いていて（アドレスは 127.0.0.1）、ほかのパソコンからはアクセスできません。
- レポートにパスワードやキーらしきものが出てきた場合は、大部分を自動で伏せて表示します。レポートそのものから秘密情報が漏れないようにするためです。

## よくある質問

**開こうとすると「開けません」や「壊れています」と表示される**
上の「はじめて開く」の手順に従って、「プライバシーとセキュリティ」で「このまま開く」を押してください。

**ダブルクリックしてからしばらく経っても、ブラウザが開かない**
初回の起動では Python をダウンロードします。回線が遅いと 2〜3 分かかることがあるので、右上の通知に注目してください。3 分を過ぎても開かない場合は、エラーメッセージが表示されます。起動の記録は `~/Library/Logs/Argus/argus.log` にあります。

**画面が固まって、何を押しても反応しない**
右上の「このアプリについて」→「**Argus を終了**」を押してから、Argus をダブルクリックして開き直してください。「このアプリについて」も押せない場合は、Mac を再起動してもかまいません。

**「Argus を「アプリケーション」フォルダに移動してから、そこから開いてください」と表示される**
「ダウンロード」フォルダから直接 Argus を開いています。この場合 macOS は一時的なコピーで Argus を動かすため、あとで移動したり更新したりすると問題が起きます。Argus を「アプリケーション」フォルダにドラッグし、そこから開いてください。

**ページに「Argus を開き直してください」と表示される**
Argus のファイルが移動されたか、新しいバージョンに入れ替わったため、古い Argus は自動で終了しました。タブを閉じて、「アプリケーション」から Argus を開き直してください。

**ページの上に赤い「Argus は終了しました」が表示される**
ページを長いあいだ操作しないでいると、Argus は自動で終了します。もう一度 Argus をダブルクリックしてください。

**スキャナーのインストールに失敗する**
インターネットにつながっていることを確かめてから、もう一度「インストール」を押してください。詳しい記録は `~/Library/Application Support/Argus/install.log` にあります。
macOS 13 より前の Mac では、SkillSpector をインストールする前に「ターミナル」で `xcode-select --install` と入力し、「コマンドライン・デベロッパ・ツール」をインストールしてください。

**スキャナーに「スキャン未完了」と表示される**
理由はレポートに書かれています。よくあるのは次のような場合です。
- 理由に `ImportError`、`dlopen`、`incompatible architecture` が含まれる：そのスキャナーが壊れています。ホーム画面で再インストールしてください。
- ダウンロードに失敗した：インターネットにつながっていること、GitHub のリポジトリが公開されていることを確かめてください。非公開のリポジトリは、先に zip でダウンロードしてから「zip ファイル」でチェックしてください。

**会社のパソコンで開けない、インストールできない**
会社から支給された Mac では、Apple の認証を受けていないアプリのインストールが禁止されていることがあります。まず社内の IT 担当に相談してください。
