# Argus：使用說明

**Argus** 是一個 Mac 小工具：在安裝 Claude 等 AI 工具的「技能」（Skill）之前，請好幾個開源安全掃描工具一起檢查，再把結果整理成一份白話中文報告。

名字來自希臘神話裡的百眼巨人 Argus：身上的眼睛輪流守望，從不全部閉上。

---

## 需要什麼

- 一台 Mac（macOS 11 以上，Intel 或 M 系列晶片都可以）
  - Cisco Skill Scanner 需要 macOS 13 以上
  - macOS 13 以前的 Mac，安裝 SkillSpector 前要先裝 Apple 的「命令列開發者工具」（Argus 會提示）
- 第一次使用時需要網路（安裝 Argus 需要的程式和掃描工具）
- 不需要另外安裝 Python 或 Git

---

## 第一次使用

1. **解壓縮**：點兩下下載的 `Argus-mac-版本.zip`（例如 `Argus-mac-2.0.1.zip`），得到「Argus」。
2. **放好位置**：把 Argus 拖到「應用程式」資料夾。
   - 如果之前用過「SkillSpector 掃描」，可以把它丟到垃圾桶。已經裝好的 SkillSpector 會直接沿用，不用重裝。
3. **第一次打開**：點兩下打開。這個 App 不是從 App Store 下載的，Mac 會先擋下來，這是正常的：
   - **較新的 macOS（Sequoia 以後）**：按「完成」關掉提示 →「系統設定」→「隱私權與安全性」→ 往下捲，找到關於「Argus」的訊息 → 按「**仍要打開**」→ 再確認一次。
   - **較舊的 macOS**：在 App 圖示上按右鍵 →「打開」→ 再按「打開」。
4. **安裝 uv**：第一次會問要不要安裝 uv（用來安裝掃描工具的免費開源小程式），按「安裝」。
5. **等它打開**：第一次啟動要下載一些東西，大約 1 分鐘，之後瀏覽器會自動打開 Argus 的頁面。
6. **安裝掃描工具**：在「用哪些工具？」裡，按每個工具旁邊的「**安裝**」，每個大約 1–3 分鐘。建議全部裝。

之後點兩下 Argus 就會直接打開頁面。

## 怎麼用

### 1. 要檢查什麼？

| 選項 | 用途 |
|---|---|
| 我所有的 Claude 技能 | 自動找出這台 Mac 上 Claude 的技能和外掛，一次全部檢查 |
| 一個資料夾 | 選一個下載下來、還沒安裝的技能資料夾 |
| 一個 zip 檔 | 選一個技能的 zip 檔 |
| GitHub 網址 | 貼上公開 repo 的連結，也可以是裡面某個資料夾的連結 |
| 我的 MCP 伺服器 | 檢查 Claude Code、Claude 桌面版、外掛和 Cursor 裡設定的 MCP 伺服器。只讀設定檔，不會啟動任何伺服器，也不需要安裝掃描工具 |

一個資料夾、zip 或 repo 裡有好幾個技能時，會分開檢查，報告裡每個技能各一張卡片。

### 2. 用哪些工具？

| 工具 | 擅長 |
|---|---|
| **SkillSpector**（NVIDIA） | 專門檢查 AI 技能：提示詞注入、資料外流、危險指令、套件漏洞等 70 多種寫法 |
| **Cisco Skill Scanner**（Cisco） | 另一套專門檢查 AI 技能的規則，當作第二意見 |
| **Bandit**（PyCQA） | 檢查技能裡的 Python 程式有沒有危險寫法；沒有 Python 程式的技能會顯示「不適用」 |
| **Semgrep**（Semgrep） | 用 Argus 自己的規則檢查技能裡的 JavaScript／TypeScript 程式：執行指令、把文字當程式執行、讀取金鑰檔、改動開機設定、把資料送到可疑的地方。沒有這類程式的技能會顯示「不適用」 |
| **detect-secrets**（Yelp） | 找技能裡有沒有寫死的密碼、API 金鑰 |
| **OSV-Scanner**（Google） | 檢查技能用到的套件有沒有已知漏洞，或被通報為惡意套件。只看寫明版本的套件清單（例如 package-lock.json、寫了 == 的 requirements.txt），沒有的話顯示「不適用」。**會把套件名稱和版本送到 OSV.dev 查詢**，不會送出技能內容 |

建議全部勾選，各工具擅長的地方不同。

### 3. 開始檢查

按「開始檢查」，頁面會顯示進度。完成後報告直接出現在頁面上，也會存一份在「文件 → Argus 報告」資料夾。之前的報告可以在首頁的「最近的報告」找回來。

「開始檢查」旁邊會先告訴你有幾個技能、**預估要多久**（GitHub 網址和 zip 檔要下載解開後才知道有幾個技能，會先說每個技能大約多久）。檢查時進度畫面會顯示已經過的時間和預估還要多久。預估會越用越準：Argus 會記住每個工具在你電腦上實際花的時間。

### 提醒你重新檢查

打開 Argus 時，如果你的 Claude 技能有這些情況，首頁最上面會出現提醒：

- 上次檢查之後，技能的檔案有更新；
- 新裝了還沒檢查過的技能；
- 超過 30 天沒檢查。

按「**現在檢查**」會幫你選好「我所有的 Claude 技能」；按「稍後再說」，7 天內不會再提醒（除非又有新的更新）。Argus 只比對檔案，不會自己開始掃描。

看完報告，直接關掉瀏覽器分頁就好，Argus 會在幾分鐘後自動結束。

### 更新 Argus

有新版本時，Argus 首頁上方會出現「**有新版本**」的提示（每次打開 Argus 時檢查；也可以在「關於」按「**檢查更新**」）：

- 按「**立即更新**」：Argus 會自己下載新版、確認是官方的新版本、換掉舊版，再自動重新打開。不用下載、不用拖檔案，掃描工具和之前的報告都會保留。
- 按「**手動更新**」：照視窗裡的步驟自己下載、取代。
- 按「**稍後再說**」：這個版本就不會再提醒。

注意：

- Argus 要放在「應用程式」資料夾裡才能自動更新。
- 較新的 macOS 第一次自動更新時，可能會問要不要允許 Argus 更新 App，請按允許；如果被擋下來，Argus 會維持原本的版本，改用「手動更新」即可。
- 2.0.2 以前的版本沒有這個功能，要手動更新一次到 2.0.2，之後就能一鍵更新。
- 更新前的舊版會保留一份，萬一新版有問題可以換回來。

## 怎麼看報告

報告最上面是**一句話結論**，不用看完整份就知道該怎麼做：

- 🟢 **可以裝**（已經裝好的技能和 MCP 伺服器寫「可以繼續用」）：沒有需要擔心的地方，或標出來的都屬於「多半不用擔心」。
- 🟡 **先問人**：有幾項需要看一下。拿不準就按「複製給 Claude 判斷」，或問懂的人。
- 🔴 **不建議裝**（或「不建議用」）：有高風險的寫法。除非確定是正常功能，否則先不要用。

一次檢查很多技能時，結論會寫「幾個不建議、幾個先問人」，並列出它們的名字，點名字就會跳到那個技能。

結論是 Argus 依固定規則整理的：先看各工具的結論（取最嚴重的那一個），再扣掉「多半不用擔心」和之前看過的發現。卡片上會列出每個工具各自的結論，例如「SkillSpector 不建議安裝 · Cisco 注意 · Bandit 安全」。

每個技能底下的發現分成兩組：

- **需要看的**：建議點開來逐條看。
- **多半不用擔心的**：用固定規則挑出來、先收起來的，每一條都寫了「為什麼不用擔心」。例如只是提醒、出現在網頁樣式檔裡、只是範例檔裡的假金鑰。

每一條發現都標了是哪個工具找到的，並附上**說明**、**原文片段**和**怎麼判斷**。

> **重要：「不建議安裝」不等於有惡意。**
> 掃描工具只看寫法、不看用途，所以很常把正常功能也標起來，例如轉檔時執行工具、用你自己的 API 金鑰呼叫官方服務。
> 分組只是幫你排好閱讀順序，不會藏起任何一條，也不會改變各工具的結論。
> Bandit 不是專門為 AI 技能設計的，所以它最多只會給「注意」，不會單獨給「不建議安裝」。

**拿不準的話，交給 Claude 判斷：**

1. 按報告上方的「**複製整份報告給 Claude 判斷**」，或某個技能底下的「**複製給 Claude 判斷**」（只複製那個技能）。
2. 打開 Claude，在對話框貼上（⌘V）送出。
3. Claude 會逐條告訴你哪些是真的要擔心、哪些是誤判，最後告訴你能不能裝、要注意什麼。

### 能做的事（能力一覽）

每個技能的名稱下方，有一排圖示標出它**會做的事**：

| 圖示 | 意思 |
|---|---|
| 🌐 連網 | 會連到網路上的服務或下載東西 |
| ⚙️ 執行程式 | 會在你的電腦上執行程式或指令 |
| 📁 寫入或刪除檔案 | 會建立、修改或刪除檔案 |
| 🔑 碰觸機密或 Claude 設定 | 會讀取金鑰、.env 檔或 Claude 的設定資料夾 |
| ⚡ 自動執行 | 會在特定時機自動執行，不用你叫它 |
| 📦 安裝套件 | 會安裝其他程式或套件 |
| 📄 只有文字說明 | 以上都沒有，只是給 AI 看的說明文字 |

點一下圖示，可以看到 Argus 是根據哪個檔案的哪一行判斷的。可以用來檢查「這個寫劇本的技能，為什麼要連網？」這類不合理的地方。這是 Argus 依檔案內容推測的，不是保證。

### 標記為已看過

看完一個技能、覺得沒問題，按卡片下方的「**標記為已看過**」。之後再掃描時：

- **沒有變動**：標示「✓ 已看過」，之前看過的發現會收到「之前看過的」，不用再看一次。
- **作者更新了這個技能**：標示「⚠ 你看過之後，這個技能有更新」，並列出新增、修改、刪除了哪些檔案；新出現的發現會標上紅色的「新」。

這可以防範一種常見手法：技能一開始很乾淨，等大家都裝了，才在更新時偷偷加料。沒標過已看過的技能，Argus 也會跟上一次掃描比較，有變動就提醒。再按一次可以取消。

這個按鈕只在 Argus 裡打開報告時才會出現；直接打開存下來的報告檔案時沒有。

### MCP 伺服器的報告

選「我的 MCP 伺服器」時，每個伺服器各一張卡片，標出它設定在哪裡、怎麼執行（或連到哪個網址），以及這些提醒：

- **版本沒鎖定**：每次啟動都下載最新版，作者或盜用帳號的人發佈新版時，你的電腦會直接執行。大公司或 MCP 官方的套件會收在「多半不用擔心」。
- **每次啟動都抓 GitHub 上最新的程式碼**：沒有經過套件庫、也沒有指定版本，作者推上去的任何改動都會直接執行。
- **會把別人傳來的訊息交給 Claude**：Discord、Telegram、iMessage 這類外掛。別人傳來的文字可能被 Claude 當成指令照做，沒在用就關掉。
- **連線沒有加密**：用 http:// 連到外部服務。
- **金鑰直接寫在設定檔裡**：保管習慣的提醒，金鑰在報告裡一律遮住。
- **Docker 權限太高、能存取整個家目錄**：給的權限超過一般需要。

這些多半是設定習慣的問題，不代表伺服器有惡意；拿不準的話一樣可以按「複製給 Claude 判斷」。

## 隱私與安全

- 「已看過」的紀錄和每次掃描的比對資料，只存在你的電腦上，不會上傳。
- 檢查 MCP 伺服器時，Argus 只讀取設定檔，不會啟動伺服器；設定裡的金鑰在報告中一律遮住。
- 所有掃描都在你的電腦上進行，**技能內容不會被上傳**，也不會送給 AI 服務。
- 只有這些情況會連網：
  - 安裝 Argus 需要的程式和掃描工具。
  - 用 GitHub 網址掃描時，下載那個技能。
  - 查詢技能用到的套件有沒有已知漏洞（只送出套件名稱和版本到 [OSV.dev](https://osv.dev)，用 OSV-Scanner 時）。
  - 到 GitHub 查 Argus 有沒有新版本（每次打開 Argus 時，或按「檢查更新」時），以及你按「立即更新」時下載新版。不會送出任何技能或報告的內容。
- Argus 的頁面只在你的電腦上運作（網址是 127.0.0.1），其他電腦連不進來。
- 報告裡如果出現疑似密碼或金鑰，會自動遮住大部分內容，避免報告本身把機密傳出去。

## 常見問題

**打開時說「無法打開」或「已損毀」**
照上面「第一次打開」的步驟，到「隱私權與安全性」按「仍要打開」。

**點兩下後過了很久，瀏覽器都沒打開**
第一次啟動要下載 Python，網路慢時可能要 2–3 分鐘，請留意右上角的通知。超過 3 分鐘還沒打開，會跳出錯誤訊息；啟動紀錄在 `~/Library/Logs/Argus/argus.log`。

**畫面卡住、按什麼都沒反應**
按右上角「關於」→「**結束 Argus**」，再點兩下 Argus 重新打開。連「關於」都按不了的話，重新開機也可以。

**跳出「請先把 Argus 拖到「應用程式」資料夾，再從那裡打開」**
你是直接從「下載項目」打開 Argus 的。macOS 這時會用一份暫時的副本執行，之後搬動或更新就會出問題。把 Argus 拖進「應用程式」資料夾，再從那裡打開就好。

**頁面顯示「Argus 需要重新打開」**
Argus 的檔案被搬動或換成新版了，舊的 Argus 已經自動結束。關掉分頁，從「應用程式」重新打開 Argus 即可。

**頁面上方出現紅色的「Argus 已經關閉了」**
頁面閒置太久時，Argus 會自動結束。重新點兩下 Argus 就好。

**某個工具安裝失敗**
確認網路正常後再按一次「安裝」。完整紀錄在 `~/Library/Application Support/Argus/install.log`。
如果是 macOS 13 以前的 Mac，安裝 SkillSpector 前要先在「終端機」輸入 `xcode-select --install`，裝好「命令列開發者工具」。

**某個工具顯示「沒掃完」**
報告裡會寫出原因。常見的有：
- 原因裡有 `ImportError`、`dlopen`、`incompatible architecture`：那個工具壞掉了，在首頁把它重新安裝一次。
- 下載失敗：確認網路正常，而且 GitHub repo 是公開的。私人 repo 請先下載成 zip，再用「一個 zip 檔」。

**公司電腦打不開或裝不起來**
公司配發的 Mac 可能禁止安裝未經 Apple 認證的 App，請先詢問公司 IT。
