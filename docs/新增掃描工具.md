# 新增一個掃描工具

每個掃描工具都是 `core/argus/scanners/` 裡的一個檔案。檔案裡定義一個 `SCANNER` 物件，Argus 啟動時會自動找到它，介面上的工具清單、「關於」裡的授權清單、報告都會一起出現，其他地方不用改。

## 1. 先確認工具適不適合

- **能完全在本機跑、不需要 AI 金鑰**：這是 Argus 對使用者的承諾。需要上傳內容或金鑰的工具，最多做成「預設不勾選」，而且要在 `summary` 寫清楚。
- **能用 uv 安裝**：PyPI 上的套件，或 `名稱 @ https://….zip` 這種原始碼網址。
- **能輸出 JSON**：解析穩定，不用去猜終端機上的文字。
- **授權允許**：Apache-2.0、MIT、BSD 都沒問題，記得加進 `THIRD_PARTY_NOTICES.md`。

## 2. 寫外掛

以 Bandit（`scanners/bandit.py`）為例，最少要有這些：

```python
import json

from .. import tools
from ..model import Finding, Outcome
from .base import Scanner, failed


def parse(data) -> Outcome:
    """把工具的 JSON 轉成 Argus 的 Outcome。和執行分開寫，才能用範例檔測試。"""
    findings = [Finding(scanner='mytool', title='中文名稱', what='這是什麼', tip='怎麼判斷',
                        severity='HIGH', file=i['file'], line=i['line'], snippet=i.get('code', ''),
                        rule=i['rule'], category=i['category'], detail=i['message'])
                for i in data['results']]
    return Outcome('mytool', 'CAUTION' if findings else 'SAFE', findings)


class MyTool(Scanner):
    id = 'mytool'                 # 不要改，報告和設定會用到
    name = 'MyTool'
    vendor = '作者'
    license = 'Apache-2.0'
    homepage = 'https://github.com/…'
    summary = '一句中文：它檢查什麼。'
    order = 50                    # 在清單裡的位置
    default_on = True
    exe = 'mytool'                # uv 安裝後，~/.local/bin 裡的指令名稱
    package = 'mytool'            # uv tool install 的對象

    def scan(self, skill_dir, work):
        out = work / 'mytool.json'
        code, _, err = tools.run([tools.find_exe(self.exe), 'scan', str(skill_dir), '--json', str(out)])
        try:
            return parse(json.loads(out.read_text(encoding='utf-8')))
        except (OSError, ValueError):
            return failed(self.id, tools.last_lines(err))


SCANNER = MyTool()
```

### 結論（verdict）怎麼給

| 值 | 意思 |
|---|---|
| `DO_NOT_INSTALL` | 不建議安裝。只有專門針對 AI 技能、而且找到高風險寫法時才用 |
| `CAUTION` | 注意 |
| `SAFE` | 安全 |
| `SKIPPED` | 不適用（用 `applies_to()` 回傳 False 時，Argus 會自動給） |
| `ERROR` | 沒掃完，用 `failed(id, 原因)` 產生 |

每個技能的總結論，取所有工具裡最嚴重的一個；`SKIPPED` 和 `ERROR` 不算進去。不是針對 AI 技能設計的通用工具（例如 Bandit），最多給 `CAUTION`。

### 「多半不用擔心」

把 `Finding.calm` 設成一句中文理由，那一條就會被收到「多半不用擔心」，並顯示理由。規則要保守：寧可多給人看一條，也不要把真的問題收起來。

### 可以覆寫的其他方法

- `applies_to(skill_dir)`：沒有它要看的檔案時回傳 False（例如 Bandit 只看 `.py`）。
- `preflight()`：這台電腦裝不了時，回傳原因（例如 macOS 版本太舊）。
- `install_command(uv)`：需要特別的安裝方式時。
- `version_args`：工具的版本參數不是 `--version` 時。

## 3. 測試

1. 把工具真實輸出的 JSON 存成 `tests/fixtures/mytool.json`（可以先刪掉不必要的部分）。
2. 在 `tests/test_argus.py` 加測試：結論對不對、中文標題對不對、「多半不用擔心」的規則有沒有分對。
3. 執行：

```bash
python3 -m unittest discover tests
```

4. 在 `tests/preview_server.py` 的 `PARSERS` 加上你的 `parse`，就能在介面上看到效果：

```bash
python3 tests/preview_server.py
```

## 4. 收尾

- `THIRD_PARTY_NOTICES.md`、`docs/使用說明.md` 的工具表格加上新工具。
- `CHANGELOG.md` 記一筆，`core/argus/__init__.py` 的 `VERSION` 加一版。
- `bash mac/build.sh` 重新打包。
