# Argus (Windows 버전): 사용 설명서

**Argus**는 Windows용 작은 도구예요. Claude 같은 AI 도구에 '스킬'(Skill)을 설치하기 전에, 여러 오픈소스 보안 스캐너로 함께 검사하고 그 결과를 알기 쉬운 보안 보고서 한 장으로 정리해 줘요.

이름은 그리스 신화에 나오는 눈이 백 개 달린 거인 아르고스(Argus)에서 따왔어요. 몸에 달린 눈이 번갈아 지켜보기 때문에 모든 눈을 한꺼번에 감는 일이 없어요.

---

## 필요한 것

- Windows 10 또는 Windows 11 (일반 Intel/AMD 컴퓨터와 ARM 컴퓨터 모두 가능)
- 처음 쓸 때는 인터넷 연결이 필요해요. (Argus에 필요한 프로그램과 스캐너를 설치해요.)
- Python이나 Git을 따로 설치할 필요는 없어요.

---

## 처음 사용하기

1. **압축 풀기**: 내려받은 `Argus-win-버전.zip`을 오른쪽 클릭 → '**모두 압축 풀기**'를 누르면 'Argus' 폴더가 나와요.
   (꼭 먼저 압축을 풀어 주세요. zip 안에서 바로 더블 클릭하면 열리지 않아요.)
2. **자리 잡기**: Argus 폴더를 통째로, 찾기 쉽고 나중에 함부로 옮기지 않을 곳에 둬요. 예: '문서'.
3. **처음 열기**: 폴더 안의 **Argus.cmd**를 더블 클릭해요. 이 도구는 Microsoft Store에서 받은 것이 아니라서 Windows가 먼저 막을 수 있어요. 정상이에요.
   - 파란색 '**Windows의 PC 보호**' 창이 뜨면: '**추가 정보**' → '**실행**'을 눌러요.
   - '**파일 열기 - 보안 경고**'가 뜨면: '**실행**'을 눌러요.
4. **uv 설치**: 처음에 uv(스캐너를 설치할 때 쓰는 무료 오픈소스 작은 프로그램)를 설치할지 물어보면 '**예**'를 눌러요.
5. **열릴 때까지 기다리기**: 처음 실행할 때는 내려받을 것이 있어서 1분 정도 걸려요. 작은 창에 진행 상황이 나오고, 그다음 브라우저에서 Argus 페이지가 자동으로 열려요.
6. **스캐너 설치**: '어떤 스캐너를 쓸까요?'에서 오른쪽 위의 '**모두 설치**'를 누르면 모든 스캐너를 차례로 설치해요. (스캐너마다 1–3분 정도) 스캐너 옆의 '설치'를 눌러 하나씩 설치해도 돼요. 모두 설치되면 이 영역이 한 줄로 접혀요. 바꾸고 싶으면 '조정'을 눌러요.

처음 연 뒤에는 **시작 메뉴**와 **바탕 화면**에 Argus 아이콘이 있는 바로 가기가 생겨요. 다음부터는 거기서 열면 되고, Argus.cmd를 다시 찾을 필요가 없어요.

---

## 사용 방법

> Argus는 컴퓨터의 언어를 따라가요. 다른 언어로 보고 싶다면 페이지 오른쪽 위, 테마 전환 버튼 옆에서 언어를 바꿀 수 있어요.
> 처음에는 다크 모드로 열려요. 라이트 모드로 바꾸려면 오른쪽 위의 달 버튼을 눌러요. 한 번 더 누르면(해) 다시 다크 모드가 돼요.

### 1. 무엇을 검사할까요?

| 선택 항목 | 용도 |
|---|---|
| 내 Claude 스킬 | 이 컴퓨터에 있는 Claude의 스킬과 플러그인(`C:\Users\내 이름\.claude` 안)을 자동으로 찾아서 한 번에 모두 검사해요 |
| 폴더 하나 | 내려받았지만 아직 설치하지 않은 스킬 폴더를 하나 골라요 |
| zip 파일 하나 | 스킬의 zip 파일을 하나 골라요 |
| GitHub 주소 | 공개 repo의 링크를 붙여 넣어요. repo 안의 특정 폴더 링크도 돼요 |
| 내 MCP 서버 | Claude Code, Claude 데스크톱 앱, 플러그인, Cursor에 설정된 MCP 서버를 검사해요. 설정 파일만 읽고, 서버는 하나도 실행하지 않아요. 스캐너를 설치할 필요도 없어요 |

폴더, zip, repo 하나에 스킬이 여러 개 들어 있으면 따로따로 검사하고, 보고서에서 스킬마다 카드가 한 장씩 나와요.

### 2. 어떤 스캐너를 쓸까요?

| 스캐너 | 잘하는 것 |
|---|---|
| **SkillSpector** (NVIDIA) | AI 스킬 전용 검사: 프롬프트 주입, 데이터 유출, 위험한 명령, 패키지 취약점 등 70가지가 넘는 패턴 |
| **Cisco Skill Scanner** (Cisco) | AI 스킬을 전문으로 검사하는 또 하나의 규칙 모음. 두 번째 의견으로 써요 |
| **Bandit** (PyCQA) | 스킬 안의 Python 코드에 위험한 패턴이 있는지 검사해요. Python 코드가 없는 스킬은 '해당 없음'으로 표시돼요 |
| **Semgrep** (Semgrep) | Argus 자체 규칙으로 스킬 안의 JavaScript/TypeScript 코드를 검사해요: 명령 실행, 텍스트를 코드로 실행, 키 파일 읽기, 시동 설정 변경, 수상한 곳으로 데이터 보내기. 이런 코드가 없는 스킬은 '해당 없음'으로 표시돼요 |
| **detect-secrets** (Yelp) | 스킬 안에 비밀번호나 API 키가 그대로 적혀 있는지 찾아요 |
| **OSV-Scanner** (Google) | 스킬이 쓰는 패키지에 알려진 취약점이 있는지, 악성 패키지로 신고된 적이 있는지 검사해요. 버전이 적힌 패키지 목록(예: package-lock.json, == 이 적힌 requirements.txt)만 보고, 없으면 '해당 없음'으로 표시돼요. **패키지 이름과 버전을 OSV.dev로 보내서 조회하지만**, 스킬 내용은 보내지 않아요 |

**Argus도 직접 검사해요:**
- **파일**: 스캐너가 읽을 수 없는 파일(컴파일된 프로그램, 압축 파일)이 스킬에 들어 있는지, 버전 고정이 안 된 패키지 목록이 있는지 확인해요.
- **플러그인의 훅과 명령** ('내 Claude 스킬'을 검사할 때): 플러그인은 훅을 설정해서, 메시지를 보낼 때마다 또는 Claude가 도구를 쓸 때마다 명령을 자동으로 실행할 수 있어요. Argus는 플러그인마다 자동으로 실행되는 명령을 모두 보여 주고, 스스로 인터넷에 연결하거나, 프로그램을 내려받아 실행하거나, 키를 건드리거나, 시동 설정을 바꾸는 것을 표시해요. 그 명령이 쓰는 프로그램도 검사해요. 보고서에는 '플러그인 이름 (플러그인의 훅, 명령, 프로그램)'으로 나와요.

**스캐너의 새 버전이 나오면:** Argus를 열었을 때 새 버전이 있는 스캐너 옆에 '새 버전 x.y'와 '업데이트' 버튼이 나와요. 누르면 새 버전으로 바뀌어요. (1–3분 정도) Argus는 PyPI와 GitHub에서 버전 번호만 확인하고, 아무 내용도 보내지 않아요. 스캐너는 저절로 업데이트되지 않으니 '새 버전'이 보이면 업데이트하는 걸 권해요. 특히 SkillSpector와 Cisco는 새로운 공격 방법을 잡으려면 새 버전의 규칙이 필요해요.

### 3. 검사 시작

'검사 시작'을 누르면 페이지에 진행 상황이 나와요. 끝나면 보고서가 페이지에 바로 나타나고, '문서' 폴더 안의 `Argus 보고서` 폴더에도 한 부 저장돼요. 지난 보고서는 첫 화면의 '최근 보고서'에서 다시 찾을 수 있어요.

'검사 시작' 옆에 스킬이 몇 개인지, **얼마나 걸릴지 예상 시간**을 먼저 알려 줘요. (GitHub 주소와 zip 파일은 내려받아 풀어 봐야 스킬이 몇 개인지 알 수 있어서, 먼저 스킬 하나당 걸리는 시간을 알려 줘요.) 검사 중에는 진행 화면에 지금까지 걸린 시간과 남은 예상 시간이 나와요. 쓸수록 예상이 정확해져요. Argus가 스캐너마다 내 컴퓨터에서 실제로 걸린 시간을 기억하거든요.

### 다시 검사하라고 알려 줘요

Argus를 열었을 때 Claude 스킬이 이런 상태라면 첫 화면 맨 위에 알림이 나와요.

- 지난번 검사 이후 스킬 파일이 업데이트됐을 때
- 아직 검사하지 않은 스킬을 새로 설치했을 때
- 30일 넘게 검사하지 않았을 때

'**지금 검사**'를 누르면 '내 Claude 스킬'을 골라 둬요. '나중에'를 누르면 7일 동안 다시 알리지 않아요. (새 업데이트가 또 생기면 알려 줘요.) Argus는 파일을 비교만 하고, 스스로 검사를 시작하지는 않아요.

스킬이 많아서 오래 걸릴 때는 진행 화면 아래의 '**검사 중지**'를 누르면 돼요. 이미 검사가 끝난 부분은 그대로 보고서로 만들어져요.

보고서를 다 봤으면 브라우저 탭을 그냥 닫으면 돼요. Argus는 몇 분 뒤에 저절로 종료돼요.

### Claude와 함께 쓰기

첫 화면 아래쪽의 '**Claude와 함께 쓰기**'에 스위치가 두 개 있어요.

**Claude에서 바로 Argus에게 검사 맡기기**
켜면 Argus가 Claude에 'argus'라는 스킬을 추가해요. 그다음 **Claude Code**(터미널, 또는 데스크톱 앱의 Code 탭)에서 이렇게 말하면 돼요.

- "이 스킬 설치하기 전에 검사해 줘: https://github.com/…"
- "내가 설치한 스킬은 안전해?"
- "내 MCP 서버 검사해 줘"

Claude가 직접 Argus로 검사하고, 결과를 쉬운 말로 알려 줘요. Argus를 열거나 복사해서 붙여 넣을 필요가 없어요. Claude에게 스킬 설치를 부탁하면, Claude가 먼저 검사해서 결론을 알려 준 다음 설치해요.

> 일반 Claude 대화(웹, 휴대폰 앱)에서는 내 컴퓨터의 프로그램을 실행할 수 없어서, 이 스킬은 Claude Code에서만 쓸 수 있어요.
> 내부적으로는 Argus가 만든 `argus` 명령(`%USERPROFILE%\.local\bin\argus.cmd`)을 써요. Argus를 열 때마다 이 명령을 업데이트하니, Argus를 옮기거나 업데이트한 뒤에는 한 번만 열어 주면 돼요.

**새로 설치한 스킬 자동 검사**: 지금은 Mac 버전에만 있고, Windows 버전에는 나중에 추가될 예정이에요. Argus를 열 때 나오는 '다시 검사하라고 알려 줘요' 알림으로도 어떤 스킬이 업데이트됐는지 알 수 있어요.

### Argus 업데이트

새 버전이 나오면 첫 화면 위쪽에 '**새 버전이 있어요**' 안내가 나와요. (Argus를 열 때마다 확인해요. '정보'에서 '**업데이트 확인**'을 눌러도 돼요.)

- '**지금 업데이트**'를 누르면: Argus가 직접 새 버전을 내려받고, 공식 새 버전인지 확인한 뒤, 옛 버전을 바꾸고 자동으로 다시 열어요. 스캐너와 지난 보고서는 그대로 남고, 바로 가기도 다시 만들 필요가 없어요.
- '**직접 업데이트**'를 누르면: 창에 나오는 순서대로 직접 내려받아 바꿔요.
- '**나중에**'를 누르면: 이 버전은 다시 알리지 않아요.

자동 업데이트에 실패하면(예: Argus 폴더가 열린 창이 있어서 파일이 사용 중일 때) Argus는 원래 버전을 그대로 유지해요. 그 창을 닫고 다시 시도하거나, 직접 업데이트하면 돼요.

## 보고서 보는 방법

보고서 맨 위에는 **한 문장 결론**이 있어서, 전부 읽지 않아도 어떻게 하면 되는지 알 수 있어요.

- 🟢 **설치해도 괜찮음** (이미 설치된 스킬과 MCP 서버는 '계속 써도 괜찮음'): 걱정할 부분이 없거나, 표시된 것이 모두 '대체로 괜찮음'에 속해요.
- 🟡 **먼저 물어보기**: 확인할 항목이 몇 가지 있어요. 판단하기 어려우면 'Claude에게 판단 맡기기(복사)'를 누르거나, 잘 아는 사람에게 물어봐요.
- 🔴 **권장하지 않음**: 위험도가 높은 패턴이 있어요. 정상적인 기능이라고 확신할 수 없다면 일단 쓰지 마세요.

여러 스킬을 한 번에 검사하면 결론에 '비권장 몇 개, 먼저 물어보기 몇 개'처럼 쓰고 이름을 보여 줘요. 이름을 누르면 그 스킬로 바로 가요. '계속 써도 괜찮음'인 스킬은 맨 끝에 이름만 한 줄로 모아 두고, 펼쳐야 자세한 내용이 보여요. 스킬이 많은 보고서에는 위쪽에 필터 줄이 있어서, 특정 결론만 보거나 이름을 입력해 스킬을 찾을 수 있어요. 카드마다 '자세한 정보'에 스캐너별 결과와 스킬이 할 수 있는 일이 있어요. 파일로 저장하거나 다른 사람에게 보여 주려면 브라우저의 '인쇄 → PDF로 저장'을 쓰면 돼요.

같은 스캐너의 같은 종류 알림은 카드 한 장으로 합쳐요. 예를 들어 '총 14곳'처럼 나오고, 14번 반복해서 보여 주지 않아요.

결론은 Argus가 정해진 규칙에 따라 정리한 거예요. 먼저 스캐너별 결론을 보고(가장 심각한 것을 골라요), 여기서 '대체로 괜찮음'과 전에 확인한 항목을 빼요. 카드에는 스캐너마다의 결론도 나와요. 예: 'SkillSpector 설치 비권장 · Cisco 주의 · Bandit 안전'.

스킬마다 발견된 내용은 '**확인할 항목**'과 '**대체로 괜찮은 항목**' 두 묶음으로 나뉘어요. 뒤쪽은 정해진 규칙으로 골라낸 뚜렷한 오탐이고, 하나하나에 '왜 걱정하지 않아도 되는지'가 적혀 있어요.

판단하기 어려우면 '**Claude에게 판단 맡기기(복사)**'를 누르고, Claude 대화에 붙여 넣어 보내요. Claude가 항목마다 정말 걱정해야 할 것을 알려 줘요.

> **'설치 비권장'이 악성이라는 뜻은 아니에요.** 스캐너는 쓰임새가 아니라 코드 패턴만 보기 때문에, 정상적인 기능도 자주 표시해요.

|---|---|
| 🌐 인터넷 연결 | 인터넷의 서비스에 연결하거나 무언가를 내려받아요 |
| ⚙️ 프로그램 실행 | 내 컴퓨터에서 프로그램이나 명령을 실행해요 |
| 📁 파일 쓰기 또는 삭제 | 파일을 만들거나, 고치거나, 지워요 |
| 🔑 비밀 정보나 Claude 설정 접근 | 키, .env 파일, Claude 설정 폴더를 읽어요 |
| ⚡ 자동 실행 | 시키지 않아도 특정 시점에 자동으로 실행돼요 |
| 📦 패키지 설치 | 다른 프로그램이나 패키지를 설치해요 |
| 📄 텍스트 설명만 있음 | 위의 어느 것도 하지 않고, AI가 읽을 설명 텍스트만 있어요 |

아이콘을 누르면 Argus가 어느 파일의 몇 번째 줄을 보고 판단했는지 볼 수 있어요. "대본 쓰는 스킬이 왜 인터넷에 연결하지?" 같은 이상한 점을 찾을 때 쓸 수 있어요. Argus가 파일 내용으로 추측한 것이라 보장은 아니에요.

### 확인함으로 표시

스킬을 다 살펴보고 문제가 없다고 판단되면 카드 아래의 '**확인함으로 표시**'를 눌러요. 그다음 다시 검사하면:

- **바뀐 것이 없을 때**: '✓ 확인함'이 표시되고, 전에 확인한 항목은 '전에 확인한 항목'으로 접혀서 다시 볼 필요가 없어요.
- **만든 사람이 스킬을 업데이트했을 때**: '⚠ 확인한 뒤에 이 스킬이 업데이트됐어요'가 표시되고, 어떤 파일이 추가, 수정, 삭제됐는지 보여 줘요. 새로 나온 항목에는 빨간색 '새 항목' 표시가 붙어요.

이렇게 하면 흔한 수법 하나를 막을 수 있어요. 처음에는 깨끗한 스킬이었다가, 많은 사람이 설치한 뒤에 업데이트로 몰래 무언가를 끼워 넣는 수법이에요. 확인함으로 표시하지 않은 스킬도 Argus가 지난번 검사와 비교해서, 바뀐 게 있으면 알려 줘요. 한 번 더 누르면 취소돼요.

이 버튼은 Argus 안에서 보고서를 열 때만 나와요. 저장해 둔 보고서 파일을 직접 열 때는 나오지 않아요.

### MCP 서버 보고서

'내 MCP 서버'를 고르면 서버마다 카드가 한 장씩 나오고, 어디에 설정돼 있는지, 어떻게 실행되는지(또는 어느 주소에 연결하는지), 그리고 다음과 같은 알림을 보여 줘요.

- **버전 고정 안 됨**: 실행할 때마다 최신 버전을 내려받아요. 만든 사람이나 계정을 훔친 사람이 새 버전을 올리면 내 컴퓨터에서 바로 실행돼요. 큰 회사나 MCP 공식 패키지는 '대체로 괜찮음'에 들어가요.
- **실행할 때마다 GitHub의 최신 코드를 가져옴**: 패키지 저장소를 거치지 않고 버전도 정하지 않아서, 만든 사람이 올린 변경이 무엇이든 바로 실행돼요.
- **다른 사람이 보낸 메시지를 Claude에게 넘김**: Discord, Telegram, iMessage 같은 플러그인이에요. 다른 사람이 보낸 글을 Claude가 명령으로 받아들여 그대로 따를 수 있어요. 쓰지 않는다면 꺼 두세요.
- **연결이 암호화되지 않음**: http:// 로 외부 서비스에 연결해요.
- **키가 설정 파일에 그대로 적혀 있음**: 관리 습관에 대한 알림이에요. 보고서에서 키는 항상 가려져요.
- **Docker 권한이 너무 높음, 홈 폴더 전체에 접근 가능**: 보통 필요한 것보다 많은 권한을 주고 있어요.

대부분 설정 습관의 문제이고, 서버가 악성이라는 뜻은 아니에요. 판단하기 어려우면 여기서도 'Claude에게 판단 맡기기(복사)'를 누르면 돼요.

## 개인정보와 보안

- '확인함' 기록과 검사할 때마다 쓰는 비교 데이터는 내 컴퓨터에만 저장되고, 업로드되지 않아요.
- MCP 서버를 검사할 때 Argus는 설정 파일만 읽고 서버를 실행하지 않아요. 설정에 들어 있는 키는 보고서에서 항상 가려져요.
- 모든 검사는 내 컴퓨터에서 이루어지고, **스킬 내용은 업로드되지 않으며** AI 서비스로 보내지도 않아요.
- 인터넷에 연결하는 경우는 다음뿐이에요: Argus에 필요한 프로그램과 스캐너를 설치할 때, 스캐너의 새 버전을 확인할 때(버전 번호만 확인해요), 내가 지정한 GitHub 스킬을 내려받을 때, 패키지에 알려진 취약점이 있는지 조회할 때(OSV-Scanner를 쓸 때, 패키지 이름과 버전만 [OSV.dev](https://osv.dev)로 보내요), GitHub에서 Argus의 새 버전을 확인하고 '지금 업데이트'를 눌렀을 때 내려받을 때.
- Argus 페이지는 내 컴퓨터에서만 작동해요. (주소는 127.0.0.1) 다른 컴퓨터에서는 접속할 수 없어요.

## 자주 묻는 질문

**더블 클릭하면 'Windows의 PC 보호'가 나와요**
위의 '처음 열기' 순서대로 '추가 정보' → '실행'을 눌러요. 그다음부터 시작 메뉴나 바탕 화면의 바로 가기로 열면 다시 나오지 않아요.

**더블 클릭하고 한참 지나도 브라우저가 열리지 않아요**
처음 실행할 때는 Python을 내려받아야 해서, 인터넷이 느리면 2–3분 걸릴 수 있어요. 3분이 넘어도 열리지 않으면 오류 메시지가 떠요. 기록은 `%APPDATA%\Argus\logs`에 있어요. (파일 탐색기의 주소 표시줄에 이 경로를 붙여 넣으면 열 수 있어요.)

**폴더를 고르는 창이 나오지 않아요**
브라우저 뒤에 열릴 때가 있어요. 작업 표시줄을 확인해 보세요.

**화면이 멈추고 아무것도 눌리지 않아요**
오른쪽 위의 '정보' → '**Argus 종료**'를 누른 다음, Argus를 다시 열어요.

**스캐너 설치에 실패했거나 '검사 미완료'가 표시돼요**
인터넷 연결을 확인한 뒤 다시 시도해요. 보고서의 '검사 미완료' 옆 괄호에 이유가 적혀 있어요. 스캐너가 망가졌으면 첫 화면에 '다시 설치'가 나와요.

**회사 컴퓨터에서 열리지 않거나 설치가 안 돼요**
회사에서 지급한 컴퓨터는 PowerShell 스크립트 실행이나 소프트웨어 설치를 막아 둘 수 있어요. 먼저 회사 IT 담당자에게 문의해 주세요.

**지우고 싶어요**
Argus 폴더와 시작 메뉴, 바탕 화면의 Argus 바로 가기를 지우면 돼요. 보고서는 '문서' 폴더 안의 `Argus 보고서` 폴더에 있어요. 남겨 둘지는 직접 정하면 돼요.

## 면책 조항

검사 결과는 참고용이며, 스킬이 반드시 안전하다거나 반드시 해롭다는 뜻이 아니에요. 각 스캐너는 알려진 패턴만 찾을 수 있어서 오탐이 있을 수 있고, 새롭거나 일부러 숨긴 수법은 놓칠 수도 있어요. '대체로 괜찮음'은 정해진 규칙에 따라 나눈 묶음일 뿐, 문제가 없다는 보장은 아니에요. 설치할지, 어떻게 쓸지는 스스로 판단하고 그 위험도 직접 책임져야 해요. Argus는 MIT 라이선스에 따라 '있는 그대로' 제공되며 어떤 보증도 하지 않아요. 만든 사람은 이 도구를 쓰거나 결과를 바탕으로 내린 결정으로 생긴 어떤 손해에도 책임지지 않아요. Argus는 독립적인 오픈소스 프로젝트로, NVIDIA, Cisco, PyCQA, Yelp, Anthropic 등 어떤 회사나 조직과도 관계가 없고 그들의 보증을 받지도 않았어요.
